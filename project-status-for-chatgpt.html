1. Architecture Overview

The application implements a decoupled, high-resilience architecture:

  • Core Engine (Python 3.9+): core/engine.py and platform_adapters/macos.py provide deterministic volume discovery, unmounting, remounting, safe state persistence (state.json), and idle sleep monitoring.
  • Native Menu Bar App (Swift): ui/SafeEjectMenuBar.swift runs native status item lifecycle, system sleep (NSWorkspace.willSleepNotification), wake (NSWorkspace.didWakeNotification), and logout/shutdown hooks (NSWorkspace.willPowerOffNotification, NSApplication.willTerminateNotification).
  • Interactive UI Component: ui/components/SafeDriveEjectorCard.html rendered within native WKWebView via IPC bridge (window.webkit.messageHandlers).

2. Hardware Baseline (Transcend StoreJet)

Target physical hardware verified through macOS system profiling:

  • Device: StoreJet Transcend (480 GB SSD)
  • Vendor ID (VID): 0x2174 • Product ID (PID): 0x2000
  • Controller / Bridge: ASMedia ASM1153E / Realtek USB-to-SATA Bridge
  • SAT Support: Verified (S.M.A.R.T. status active)
  • Kernel Node: Root device /dev/disk7 with APFS container /dev/disk8

# Subsystem / Requirement Implementation Detail Status
1 Safe Sleep Behavior Normal Sleep exclusively uses diskutil unmount on volume mount points. Device node (/dev/disk7) remains attached to the USB bus. No physical diskutil eject is executed during sleep, ensuring background auto-wake remains technically possible. FIXED & VERIFIED
2 Isolated Auto-Wake Auto-wake logic in engine.py:remount_all_ejected(only_if_recorded=True) and cli.py:cmd_remount_all restores only drives explicitly recorded in state.json as sleeping. Unrelated external drives are strictly ignored. FIXED & VERIFIED
3 System Sleep Hook NSWorkspace.willSleepNotification triggers python3 main.py idle-sleep. Physical USB link stays alive; filesystem cache is flushed and unmounted before macOS enters sleep. FIXED & VERIFIED
4 Before Logout Hook ui/SafeEjectMenuBar.swift registers synchronous hooks on NSWorkspace.willPowerOffNotification and NSApplication.willTerminateNotification to execute idle-sleep before the user session ends. FIXED & VERIFIED
5 Dynamic Processing UI IPC bridge triggers window.onOperationStart(cmd, target) with instant action labels ("Mounting...", "Unmounting...", "Safe Sleep...", "Ejecting...") and transitions to "Ready" / "System Idle". Stale "Processing.........." text removed. FIXED & VERIFIED

7 Drive-Specific Scoping Per-row Mount/Unmount commands target only the specific disk identifier passed. Global actions target selected/managed disks. VERIFIED
