1. Architecture Overview

The application implements a decoupled, high-resilience architecture:

  • Core Engine (Python 3.9+): core/engine.py and core/volume_manager.py provide deterministic volume discovery, safe volume unmounting, LED-OFF parent physical sleep, selective wake remounting, safe state persistence (ejected_state.json), and idle sleep monitoring.
  • Native Menu Bar App (Swift): ui/SafeEjectMenuBar.swift runs native status item lifecycle, system sleep (NSWorkspace.willSleepNotification), wake (NSWorkspace.didWakeNotification), and logout/shutdown hooks (NSWorkspace.willPowerOffNotification, NSApplication.willTerminateNotification).
  • Interactive UI Component: ui/components/SafeDriveEjectorCard.html rendered within native WKWebView via IPC bridge (window.webkit.messageHandlers).

2. Hardware Baseline (Transcend StoreJet)

Target physical hardware verified through macOS system profiling and live testing:

  • Device: StoreJet Transcend (480 GB SSD)
  • Vendor ID (VID): 0x2174 • Product ID (PID): 0x2000
  • Controller / Bridge: ASMedia ASM1153E USB-to-SATA Bridge
  • Kernel Nodes: Root device /dev/disk7 with APFS containers /dev/disk8 and /dev/disk9
  • Partitions: disk8s1 (support-external-drive) and disk9s1 (Macbook Backup)

# Subsystem / Requirement Implementation Detail Status
1 LED-OFF Deep Sleep Sequence: sync → safely unmount all mounted volumes of parent drive → abort parent eject if any volume unmount fails → eject parent physical disk (diskutil eject disk7) to place ASMedia bridge into deep standby and turn SSD LED completely OFF while USB cable remains connected. FIXED & VERIFIED
2 Selective Wake / Remount Selective remounting is confirmed on live hardware: mounting an individual volume (e.g. diskutil mount disk8s1) wakes the SSD and turns the LED ON while leaving other volumes (e.g. disk9s1) unmounted. ejected_state.json dynamically updates. FIXED & VERIFIED
3 Isolated Auto-Wake Auto-wake logic in engine.py:remount_all_ejected(only_if_recorded=True) and cli.py:cmd_remount_all restores only drives explicitly recorded in ejected_state.json as sleeping. Unrelated external drives are strictly ignored. FIXED & VERIFIED
4 System Sleep Hook NSWorkspace.willSleepNotification triggers python3 main.py idle-sleep. Physical USB link stays alive; filesystem cache is flushed, volumes unmounted, and parent ejected for LED-OFF standby before sleep. FIXED & VERIFIED
5 Before Logout Hook ui/SafeEjectMenuBar.swift registers synchronous hooks on NSWorkspace.willPowerOffNotification and NSApplication.willTerminateNotification to execute idle-sleep before the user session ends. FIXED & VERIFIED
6 Dynamic Processing UI IPC bridge triggers window.onOperationStart(cmd, target) with instant action labels ("Mounting...", "Unmounting...", "Deep Sleep...", "Ejecting Safely...") and transitions to "Ready" / "System Idle". Stale text removed. FIXED & VERIFIED
7 Accurate Drive Count Removed #diskCountBars and .count-bars that rendered repetitive bars (IIII). Counter strictly renders true numeric integer strings (0, 1, 2, ...). FIXED & VERIFIED
8 Eject Now Segregation Eject Now is reserved exclusively for physical unplugging. It clears ejected_state.json completely, guaranteeing no background auto-wake occurs after unplugging. VERIFIED
9 Safety Realism & Abort Gate If any volume unmount encounters a busy file, parent eject is aborted, preventing data loss. No raw ATA/SCSI power-down commands are used, ensuring SATA bridge reliability. DOCUMENTED & BOUNDED
