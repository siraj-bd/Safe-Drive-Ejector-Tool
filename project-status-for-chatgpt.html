1. Architecture Overview

The system is built on a high-resilience, multi-layer hybrid architecture:

  • Core Engine (Python 3.9+): core/engine.py and core/volume_manager.py handle safe deterministic unmounting, APFS Time Machine snapshot teardown, parent physical disk ejection (diskutil eject), state persistence (ejected_state.json), and activity isolation.
  • Native Menu Bar Host (Swift / AppKit): ui/SafeEjectMenuBar.swift runs a native macOS status bar item with custom diamond indicator, manages power/sleep/wake hooks (NSWorkspace.willSleepNotification, NSWorkspace.didWakeNotification, NSWorkspace.willPowerOffNotification, NSApplication.willTerminateNotification), and hosts a borderless 100% transparent floating panel.
  • Dynamic UI Component (WebKit / HTML5 / CSS3): ui/components/SafeDriveEjectorCard.html loaded via WKWebView with bi-directional IPC messaging (window.webkit.messageHandlers.safeEjectBridge). Features exact fast-rabbit-51 card styling by dzoshi from Uiverse.io.

1 APFS Time Machine Unmount Timeout Fix Root Cause: When unmounting APFS Time Machine backup volume (disk7s1 / Macbook Backup), journal flushing took 6–10 seconds. The hardcoded 5s timeout terminated diskutil mid-flight, causing macOS diskarbitrationd to abort unmount and instantly remount the volume automatically.
Fix: In platform_adapters/macos.py, increased unmount/eject timeouts to 15 seconds, and added force unmount flag with 10s timeout to detach read-only Time Machine snapshot mounts (/Volumes/.timemachine/...) instantly. Prevents false unmount loops completely.		 FIXED & VERIFIED
2 LED-OFF Hardware Deep Sleep Sequence: sync → safely unmount all mounted child volumes → teardown APFS container snapshots → abort if any volume unmount fails → eject parent physical disk (diskutil eject disk7). Puts ASMedia bridge into deep power standby and completely turns off the physical SSD LED light while the USB cable remains connected. HARDWARE VERIFIED
3 Deep Sleep Checkbox vs Normal Sleep Replaced old Awake toggle with clear Deep Sleep checkbox in UI card:
• ON: External drives enter full hardware deep sleep with LED OFF. Mouse/touch/laptop wake will NOT auto-wake the drive; drive stays asleep until manual Mount.
• OFF: Normal sleep behavior. Drive safely unmounts and remounts automatically upon laptop activity.		 FIXED & VERIFIED
4 Timer Preset Synchronization (2M – 2H) Root Cause: Timers 5M through 2H previously stalled because disk7s1 unmount timed out, and SafeEjectMenuBar.swift didn't dynamically sync the timer preset from config.
